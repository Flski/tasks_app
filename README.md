Веб-приложение для управления задачами на фреймворке FastAPI.
Для запуска на локальном сервере:
1)В терминале (в директории с файлом "main.py") ввести команду, чтобы установить необходимые модули:
python -m pip install -r requirements.txt
2)Открыть файл "main.py"
3)В браузере ввести: http://127.0.0.1:7000
